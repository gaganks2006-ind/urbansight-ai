● 4 AGENTS ACTIVE & INGESTING

Multi-Agent Autonomous Orchestration

How the end-to-end data pipeline functions without human triage lag.

Agent 1: Edge Vision Perception

Runs quantized YOLOv8 Nano at 30 FPS on bus compute. Irrevocably blurs faces & plates on-chip, sending <15 KB GeoJSON telemetry.

Agent 2: DBSCAN Spatial Clustering

Merges repeat passes from multiple buses within a 5-meter window into a single verified civic hazard with longitudinal depth history.

Agent 3: Municipal Dispatch Agent

Automatically files official PWD work orders with exact GPS coordinates, timestamped photo evidence, and severity scores in <3 minutes.

Agent 4: Fleet Advisory Stream

Broadcasts live detour and hazard warning alerts directly to oncoming bus driver consoles via bi-directional WebSockets.
